## Notes on sourcing & attribution

- **5 portrait images** (`about/portrait`, `team/ana`, `team/rui`, `team/marta`, `team/tomas`)
  were **hand-curated** because the provided candidate file (`scripts/unsplash-candidates.json`)
  contained no portrait themes. They were selected from Unsplash CDN photo IDs and visually reviewed
  via contact sheets to confirm they are tasteful, editorial, neutral-background portraits (two women,
  two men, plus a senior-principal portrait) — not corporate headshots. Unsplash serves these images
  without authentication, but its web pages are bot-protected, so the contributors' @handles could not
  be machine-verified. Their `photographerUrl` therefore links directly to the exact Unsplash CDN asset
  rather than a profile page. **Please confirm each contributor handle before publication** — the
  Unsplash License does not require attribution, so this is a courtesy, not a legal requirement.
- All other 61 images use contributor handles taken directly from the
  provided candidate data (`scripts/unsplash-candidates.json`).
- **No images could not be sourced** — every one of the 66 required keys has all four variant
  files present, decodable, and within the requested dimensions on disk.
